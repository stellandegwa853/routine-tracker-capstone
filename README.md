RoutineTrack is a web-based student micro-routine tracker and burnout risk visualization application designed for university students.   Core Purpose: It helps students monitor daily lifestyle habits—such as sleep duration, study pacing, hydration, and perceived stress—to proactively prevent academic burnout.   Automated Risk Engine: The system calculates a rolling Burnout Risk Index (BRI) and translates those scores into immediate, personalized recovery recommendations rather than complex historical charts.   Institutional Governance: Features an administrative console that provides university wellness staff with real-time aggregated cohort health metrics and risk-flagged student oversight while strictly protecting personal student privacy.   Technical Stack: Built with a React frontend, Node.js environment, and a fully normalized PostgreSQL database on Supabase secured by Row Level Security (RLS), domain check constraints, and cryptographic bcrypt password hashing.
